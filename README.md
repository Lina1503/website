# YOUR SAFE PLACE — Ιστοσελίδα

Στατική ιστοσελίδα (HTML/CSS/JS, χωρίς framework) για τη **Λίνα Λεύκου**,
MSc Ψυχολόγο – Ψυχοθεραπεύτρια — Εγνατίας 54, Θεσσαλονίκη.

## Σχεδιαστικό σύστημα

Το site είναι **σκόπιμη αντιγραφή του [katemoodylpc.com](https://www.katemoodylpc.com/)**
(απαίτηση πελάτη). Ό,τι ακολουθεί μετρήθηκε από το ίδιο το πρότυπο:

* **Παλέτα** — τα δύο χρώματα της μάρκας από τα social της Λίνας:
  sage `#AEB9AD` και terracotta `#D3967C`. Μπαίνουν **αυτούσια** όπου
  έχουν αρκετή αντίθεση· όπου όχι, χρησιμοποιούνται παραλλαγές τους:

  | token | τιμή | πού |
  |---|---|---|
  | `--sage` | `#AEB9AD` | labels & γραμμές πάνω σε σκούρο |
  | `--sage-band` | `#3D483C` | σκούρες ζώνες (ίδια χροιά, σκουρότερο) |
  | `--sage-deep` | `#333E32` | footer |
  | `--sand` | `#DDE3DB` | ανοιχτή ζώνη «Πώς ξεκινάμε», creds, aside |
  | `--clay` | `#D3967C` | γραμμές, στολίδια, hover σε περιγράμματα |
  | `--clay-deep` | `#A35C3E` | **μικρά κείμενα σε κρεμ** (eyebrows, links) |
  | `--clay-soft` | `#E0AE96` | μικρά κείμενα πάνω σε σκούρο |

  Γιατί οι παραλλαγές: `#D3967C` πάνω σε κρεμ δίνει **2,3:1** και
  `#AEB9AD` **1,9:1** — δυσανάγνωστα για μικρά γράμματα (όριο 4,5:1).
  Τα `--clay-deep` (4,7:1) και `--sage` πάνω στο `--sage-band` (4,7:1)
  περνούν. Φόντο `#AEB9AD` με σκούρο κείμενο δίνει 7,5:1, οπότε αν
  ποτέ θελήσουμε ολόκληρη ζώνη στο καθαρό sage, δουλεύει μια χαρά.

* **Γραμματοσειρές** — τίτλοι σε `Noto Serif Display` 200 (uppercase,
  `ls .04em`): είναι η μόνη high-contrast display serif του Google Fonts
  **με ελληνικό subset**, στη θέση του `ivypresto-headline` του προτύπου.
  Κείμενο σε `Alegreya Sans` — η ίδια γραμματοσειρά με το πρότυπο, έχει
  ελληνικά. (Cormorant Garamond / Jost που υπήρχαν πριν **δεν** έχουν.)
* **Δομή αρχικής** — δίφυλλο hero, σκούρα ζώνη-ερώτηση, δύο δίφυλλες
  ενότητες με φωτογραφία που βγαίνει από την άκρη, βιογραφικό δίπλα σε
  πορτρέτο, στήλες υπηρεσιών με κάθετες γραμμές, γκαλερί, ζώνη «Πώς
  ξεκινάμε» σε άμμο (3 βήματα σε στήλες), σκούρο footer. Στην αρχική
  λεπτά **μαύρα πλαίσια** γύρω από φωτογραφίες και ανάμεσα στις ενότητες.
  Χωρίς FAQ και χωρίς πράσινη ζώνη CTA πουθενά (αίτημα πελάτισσας).
* **Οθόνη εισόδου** — κρεμ οθόνη με το λογότυπο και μια γραμμή terracotta
  που γεμίζει. Παίζει **μία φορά ανά επίσκεψη** (`sessionStorage`), όχι σε
  κάθε σελίδα, και δεν παίζει καθόλου με `prefers-reduced-motion`. Αν δεν
  τρέχει JavaScript δεν εμφανίζεται ποτέ, οπότε δεν μπλοκάρει το site.
* **Κουμπιά** — λευκό κουτί με περίγραμμα 1px που μαυρίζει στο hover (κύριο,
  πάντα «ΚΛΕΙΣΕ ΡΑΝΤΕΒΟΥ» στον ενικό) ή υπογραμμισμένο κείμενο (δευτερεύον). Καθόλου στρογγυλεμένες γωνίες, πουθενά.

Έλεγχος εμφάνισης: `python3 -m http.server` + headless Chrome με CDP
(το Chrome extension συχνά δεν συνδέεται).

## Δομή (24 σελίδες)

Μενού: Αρχική · Λίγα λόγια για μένα · Υπηρεσίες (μόνο dropdown, χωρίς
σελίδα) · Ο Χώρος · Επικοινωνία · ΚΛΕΙΣΕ ΡΑΝΤΕΒΟΥ. Τα Άρθρα (blog) είναι
μόνο στο footer.

```
index.html                     Αρχική
i-psychologos.html             «Λίγα λόγια για μένα»
o-choros.html                  Ο Χώρος — κείμενο + gallery με lightbox
epikoinonia.html               Επικοινωνία + χάρτης
ypiresies/<υπηρεσία>.html      4 σελίδες υπηρεσιών
perioches/<περιοχή>.html       7 τοπικές σελίδες SEO (Θεσσαλονίκη & συνοικίες)
blog/index.html                Άρθρα (hub)
blog/<άρθρο>.html              8 άρθρα
sitemap.xml, robots.txt        Τεχνικό SEO
assets/                        logo, logo-mark, φωτογραφίες χώρου & πορτρέτο
styles.css, main.js            Κοινό στυλ & συμπεριφορά
build/                         Γεννήτρια (data.mjs + build.mjs)
```

## Αναγέννηση σελίδων

Όλο το κείμενο ζει στο `build/data.mjs`:

```bash
node build/build.mjs
```

## Ραντεβού

Η πελάτισσα **δεν** θέλει online κρατήσεις ούτε σύνδεση ημερολογίου.
Όλα τα CTA οδηγούν στη σελίδα `epikoinonia.html` (τηλέφωνο / email).
Δεν υπάρχει Calendly.

## Πριν το live — επιβεβαιώστε

1. **Domain**: `BASE` στο `build/data.mjs` = `https://www.yoursafeplace.gr`.
2. **Συντεταγμένες χάρτη** (`lat`/`lng`): προσεγγιστικές για Εγνατίας 54.
3. **Email**: χρησιμοποιείται το προσωπικό `l.lefkou@yahoo.gr`. Αν φτιαχτεί
   εταιρικό (π.χ. `info@yoursafeplace.gr`), αλλάξτε το στο `data.mjs`.
4. Μετά το live: υποβολή `sitemap.xml` στο Google Search Console.
