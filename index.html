Κάθε άνθρωπος κουβαλά μια ιστορία.

Μια ιστορία που διαμορφώνεται μέσα από τις σχέσεις και τις εμπειρίες του. Η ψυχοθεραπεία δεν έχει στόχο να τη «διορθώσει» — είναι μια ευκαιρία να τη δούμε μαζί με καινούργια μάτια.

Αν κάτι σε δυσκολεύει, μια σχέση σε απασχολεί ή βρίσκεσαι σε μια περίοδο αλλαγής, μπορούμε να αναζητήσουμε νέους τρόπους να φροντίζεις τον εαυτό σου και τις σχέσεις που έχουν σημασία για σένα.

Η προσέγγισή μου

Η θεραπεία είναι, για μένα, μια συνεργατική διαδικασία.

Εσύ φέρνεις την ιστορία σου, τις εμπειρίες και όσα σε απασχολούν, κι εγώ είμαι εκεί ως συνοδοιπόρος, για να τα εξερευνήσουμε μαζί.

Με βάση τη συστημική και αφηγηματική προσέγγιση, βλέπουμε τον άνθρωπο μέσα στις σχέσεις και τις συνθήκες της ζωής του. Αναζητούμε νέες οπτικές, ακούμε όσα ίσως έχουν μείνει στο περιθώριο και δίνουμε χώρο σε δυνατότητες που μπορούν να ανοίξουν έναν διαφορετικό δρόμο.

Γιατί αυτό που μας δυσκολεύει δεν αφορά πάντα μόνο εμάς· συχνά αφορά και τον τρόπο που σχετιζόμαστε με τους σημαντικούς ανθρώπους στη ζωή μας.

Μπορούμε να δουλέψουμε μαζί αν

  • Θέλεις να κατανοήσεις καλύτερα τον εαυτό σου
  • Αναζητάτε ως ζευγάρι νέους τρόπους επικοινωνίας και σύνδεσης
  • Σε απασχολούν θέματα γονεϊκότητας
  • Το παιδί σου χρειάζεται υποστήριξη σε μια δύσκολη περίοδο

Λίνα Λεύκου

MSc Ψυχολόγος – Ψυχοθεραπεύτρια

Είμαι η Λίνα Λεύκου, Ψυχολόγος και Ψυχοθεραπεύτρια, με μεταπτυχιακές σπουδές στη Σχολική και Εξελικτική Ψυχολογία.

Στη θεραπευτική διαδικασία επιδιώκω να δημιουργώ μια σχέση εμπιστοσύνης και συνεργασίας, όπου μπορείς να κατανοήσεις όσα σε δυσκολεύουν, να αναγνωρίσεις τις δυνατότητές σου και να αναζητήσεις νέους τρόπους σύνδεσης με τον εαυτό σου και τους άλλους.
